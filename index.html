唱名音名标准频率操作
频率是怎么算出来的？（不想看可以跳过）

从 A4 = 440 Hz 出发，每升高一个半音，频率乘以 2 的 1/12 次方（≈1.05946）：

f = A4 × 2^((n − 69) / 12)

其中 n 是 MIDI 音号，中央 C（do）记作 60 号，A4（la）是 69 号。 所以 do4 = 261.63 Hz，re4 = 293.66 Hz，mi4 = 329.63 Hz，fa4 = 349.23 Hz， sol4 = 392.00 Hz，la4 = 440.00 Hz，xi4 = 493.88 Hz，do5 = 523.25 Hz。

音分（cent）是偏差单位：100 音分 = 1 个半音。 指针在 ±25 音分以内听起来基本就是准的，±50 音分以内算「接近」。

⑥ 存在这台电脑上的录音

使用须知 / 怎么练

✅ 第一次用，先做这 3 步

  1. 设音域：右上角「我的音域」选你的声部。你测出来是 A2–A4（110–440 Hz），选「男中音偏男高」。 音阶表里灰掉的音在你音域外，先别硬唱。
  2. 开始收音：点「开始收音」并允许麦克风（必须是 https 或 localhost）。
  3. 看实时曲线：①下面那条线会跟着你的音高实时滚动。线落在绿色带里 = 准，黄 = 偏一点，红 = 偏很多。

让它测得更准

  • 安静房间，麦克风离嘴 15~25 cm，别对着出风口。
  • 一次只唱一个长音（2~3 秒以上），唱稳了再看，别唱抖音。
  • 放参考音时戴耳机，否则麦克风会把音箱的声音也收进去。
  • 检测范围约 C2~E6。太低或太虚会显示「没听到稳定的音高」。

🎯 针对「sol、la 容易偏高」的练法

  1. 把音区调到 第 3 组（do3 = 130.81 Hz，sol3 = 196.00，la3 = 220.00）。 别在 do4 起：do4–do5 那一条音阶顶到你的天花板 A4，sol4 = 392、la4 = 440 当然上不去。
  2. 在②里点「▶ 听」，把 sol3、la3 各听 3 遍，记住那个高度。
  3. 慢慢唱 sol3 → la3，盯①的实时曲线：如果一到 sol 线就往上飘，说明你是靠往上滑找音，不是直接落在音上。
  4. 改成「先想好高度再出声」，出声后立刻看线有没有落进绿色带（±25 音分内）。
  5. 反向练：do4 → xi3 → la3 → sol3，从高往低唱更容易找准，不会越滑越高。
  6. 用④单音测试，每个音测 5 遍记分数，看哪个音最难稳。
