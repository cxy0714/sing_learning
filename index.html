频率是怎么算出来的？（不想看可以跳过）

从 A4 = 440 Hz 出发，每升高一个半音，频率乘以 2 的 1/12 次方（≈1.05946）：

f = A4 × 2^((n − 69) / 12)

其中 n 是 MIDI 音号，中央 C（do）记作 60 号，A4（la）是 69 号。 所以 do4 = 261.63 Hz，re4 = 293.66 Hz，mi4 = 329.63 Hz，fa4 = 349.23 Hz， sol4 = 392.00 Hz，la4 = 440.00 Hz，xi4 = 493.88 Hz，do5 = 523.25 Hz。

音分（cent）是偏差单位：100 音分 = 1 个半音。 指针在 ±25 音分以内听起来基本就是准的，±50 音分以内算「接近」。

⑥ 存在这台电脑上的录音

使用须知 / 怎么练

让它测得更准

  • 用 Chrome / Edge / Safari，必须是 https 或者 localhost，否则浏览器不给用麦克风。
  • 安静房间，麦克风离嘴 15~25 cm，别对着出风口。
  • 一次只唱一个长音（2~3 秒以上），唱稳了再看指针，别唱抖音。
  • 鼠标/手机靠近音箱会收进伴奏声，戴耳机最干净。
  • 你唱得太低（男低音区）或太高（哨音区）可能超出检测范围（约 C2~E6）。

针对「sol、la 容易偏高」的练法

  1. 先在②里点「听」，把 sol 和 la 的标准音各听 3 遍，记住那个高度。
  2. 慢慢唱 sol → la，看指针：如果一到 sol 指针就冲到右边很多，说明你是靠往上滑找音的，而不是直接落在音上。
  3. 改成「先想好高度再出声」：先在心里唱一次 sol，再出声，出声后立刻看是不是在 ±25 音分内。
  4. 从高往低唱：do5 → xi → la → sol，比从低往高更容易找准，因为不容易越滑越高。
  5. 用④做单音测试，每个音重复 5 次，记录分数，看哪个音最难稳。
