怎么练才有效

一次练习的流程

  1. 先听一遍：点「先听一遍」，看灰蓝色阶梯线，心里跟一遍。
  2. 自动适配音域：点「🎯 自动适配我的音域」，把歌移到你能唱的调（会显示移调了几个半音）。
  3. 慢速开唱：速度选 0.6x，戴耳机，点「开始跟唱打分」。
  4. 唱完看③成绩单：哪个音分最低，就单独回去练那一个音（回主页①用单音测试）。
  5. 熟练后提速：0.8x → 1.0x。别跳步。

打分怎么算的

  • 每个目标音，取你在这段时间里唱的音高中位数（抗抖音、抗个别爆音）。
  • 音分偏差 = 你唱的实际音高 − 目标音高（1200 音分 = 1 个八度）。
  • 单音得分 = 100 − |偏差|×1.2（0 音分 = 100 分，50 音分 = 40 分，83 音分 = 0 分）。
  • 没唱到 / 没声音 = 0 分，所以漏唱会直接拉低总分。
  • 总分 = 所有目标音得分的平均。

导出 JSON 里同时有「目标音高线」和「你的原始音高轨迹」， 我可以逐音告诉你：是整体偏高/偏低、某个音程唱不准、还是节奏跟不上。
